# Portfolio — Samuel Zerah

Site CV interactif (FR/EN) : React 19 · Vite · Tailwind v4 · Motion · Three.js (R3F) · Lenis.

```bash
npm install
npm run dev       # développement
npm run build && npm run preview   # version de production
```

- Contenu : `src/data.ts` (FR/EN, contacts)
- Scène 3D du hero : `src/components/NeuralScene.tsx`
- Effets inspirés d'Aceternity UI / Wensity UI, entièrement recodés (aucun code copié).
- Licences et crédits détaillés : voir `CREDITS.md`.
- Easter egg : code Konami ou commande `matrix` dans le terminal.
- Déploiement : GitHub Pages via `.github/workflows/deploy.yml` (push sur `main`).
